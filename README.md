# MOLI's Pear Ball — Lucky 777 Mini

单文件网页小游戏：纯 HTML + CSS + JS，零依赖、零构建，打开 `index.html` 即玩。

## 在线试玩

https://wd1508848154.github.io/moli-boxer/

## 本地运行

```bash
# 直接双击 index.html，或
python3 -m http.server 8080
# 打开 http://127.0.0.1:8080
```

## 说明

- 全部逻辑、样式、素材内联在 `index.html` 一个文件里
- 移动端竖屏/横屏均可用，触屏操作
